# l-systems_midpoint-displacement-algorithm_bezier-curve
лабораторная работа #5 по дисциплине "Компьютерная графика" «L-системы. Алгоритм midpoint displacement. Кривые Безье». команда «Графические»


## Запуск

```
python main.py
```

Нужен только Python 3.10+ (tkinter входит в стандартную поставку). Каждое задание - отдельная вкладка.

## Задание 1. L-системы

| Файл | Что |
|---|---|
| `lsystem.py` | ядро: разбор файла описания, порождение строки, интерпретация черепашкой, масштабирование под окно |
| `lsystem_app.py` | вкладка с панелью параметров и холстом (пункты 1.а и 1.б) |
| `fractals/*.txt` | тестовые описания: кривая и снежинка Коха, остров Коха, треугольник и наконечник Серпинского, дракон, Гильберт, Госпер, Леви, Пеано, куст, растение, стохастическое растение, дерево |

Формат файла описания:

```
<атом> <угол поворота> <начальное направление>
<правило №1>
<правило №2>
...
```

Правило: `X -> F+[[X]-X]-F[-FX]+X`. Несколько правил для одного символа - стохастическая система,
при каждой подстановке выбирается случайное. Строки с `#` - комментарии; подсказка `iterations: N`
в комментарии выставляет число итераций при загрузке. Команды черепашки: `F`, `G` - шаг с рисованием,
`f` - шаг без рисования, `+`/`-` - поворот влево/вправо, `|` - разворот, `[`/`]` - ветвление.
Направление: 0 - вправо, 90 - вверх.

- **1.а** - выбрать файл (или вписать описание в поле), задать число итераций, «Построить». Узор
  всегда масштабируется под холст с сохранением пропорций. «Случайность» добавляет разброс угла и
  длины шага; seed делает результат воспроизводимым.
- **1.б** - кнопка «Пример дерева 1.б» загружает `14_tree.txt` и включает режим дерева: толщина
  линии и цвет (коричневый -> зелёный) зависят от уровня вложенности скобок, углы ветвей случайно
  отклоняются. Толщина, коэффициенты утончения и укорочения регулируются ползунками.
